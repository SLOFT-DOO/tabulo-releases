Database notes

PostgreSQL

  • Schemas show as groups in the sidebar.
  • SSL: Disable, Prefer (the default), Require, Verify CA or Verify Full, with optional client key, certificate and CA files.
  • Connect through a Unix socket by putting its directory in Host/Socket, such as /tmp.
  • Bootstrap commands run after every connect.
  • Values are decoded from PostgreSQL's binary format, including numeric, dates and times, intervals, arrays, UUID, inet and jsonb.

MySQL and MariaDB

  • MySQL 8 (tested with 8.4) and MariaDB. Default port 3306.
  • Leave Database empty to list every database (tables show as shop.orders); fill it in to see just that one. System databases are hidden.
  • SSL Prefer (the default) encrypts when the server supports it and falls back otherwise; Require always encrypts. Accounts using caching_sha2_password work with SSL off too.
  • Connect through a Unix socket by putting its path in Host/Socket, such as /tmp/mysql.sock. Bootstrap commands run after every connect.
  • Values show as the mysql command line would show them: tinyint(1) as 1 or 0, JSON as text, binary data as 0x… hex.
  • Filters with "contains" are case-insensitive under the default collations.
  • Edits run in one transaction on InnoDB tables. MyISAM tables have no transactions.
  • AUTO_INCREMENT columns are filled in by the server when you leave them empty, in the grid and in imports.

SQLite

  • Open any .db, .sqlite or .sqlite3 file with Open SQLite File….
  • Structure changes SQLite can't do with ALTER TABLE use the documented table rebuild, keeping data, indexes and constraints.

Redis

  • The sidebar lists databases (db0, db1…). Keys of every type show in the grid.
  • Sign in with a password, or an ACL user and password. Host/Socket also takes a socket path such as /tmp/redis.sock.
  • The filter takes a key pattern such as session:*.
  • The query editor runs one command per line. Flush Database… in the sidebar asks first.

MongoDB

  • Connect with host and port, or a full connection string (mongodb+srv://…), including replica sets with several hosts. A password in the string is kept in the Keychain.
  • Columns are inferred from the documents. Nested values show as JSON.
  • Type ObjectId("…") and ISODate("…") in cells, filters and queries.

Elasticsearch

  • Connect with a URL (https://my-cluster.es.io). Over HTTPS, TLS mode checks the certificate against macOS (the default), a CA file you choose, or accepts any certificate.
  • Sign in with a user and password, or put an API key in the password field.
  • Indices list in the sidebar. The mapping gives the columns, with nested fields such as supplier.city.
  • Filters become query DSL, or type a Lucene query or a JSON query in the filter box.
  • Text fields sort by their .keyword sub-field. Documents can be edited, added and deleted, with values typed by the mapping.
