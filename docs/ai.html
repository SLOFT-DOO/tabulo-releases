AI access (MCP)

Tabulo includes a Model Context Protocol server, so AI apps like Claude can browse and query your connections. You decide, per connection, whether they can read, write, or not see it at all.

How it works

An MCP app starts Tabulo in the background with --mcp. Tabulo reads your saved connections and passwords from the Keychain and answers the app's requests. No window opens, and nothing leaves your Mac except what the AI app sends to its own service.

Connect Claude Desktop

  1. Open the settings

    Choose Tabulo ▸ Settings… and open MCP Server.

  2. Add it

    Under Claude Desktop, click Add to Claude Desktop. Tabulo writes the entry into Claude's config file. Or click Copy Config and add it yourself.

    {
  "mcpServers": {
    "tabulo": {
      "command": "/Applications/Tabulo.app/Contents/MacOS/Tabulo",
      "args": ["--mcp"]
    }
  }
}
  3. Restart Claude Desktop

    Quit and reopen it. Tabulo's tools appear in Claude's tools menu.

  4. Choose access per connection

    Under Access per connection (or in each connection's form, AI access (MCP)), set:

    • Off: AI apps can't see the connection.
    • Read only (the default): browse and run read-only queries. PostgreSQL, MySQL and SQLite sessions are opened read-only too, so a write can't slip through.
    • Read & write: also allows execute_statement.

Claude Code and other apps

claude mcp add tabulo --scope user -- /Applications/Tabulo.app/Contents/MacOS/Tabulo --mcp

Cursor, Codex and other MCP apps use the same command and argument. Settings shows the exact command for your copy of Tabulo.

Tools

ToolWhat it does
list_connectionsConnections AI apps may use, with type, environment and access
list_tablesTables, views, collections, indices or Redis databases
describe_tableColumns, keys, indexes, foreign keys and row count
get_rowsRows with filters, sorting and paging, the same way for every engine
run_queryRead-only SQL, Redis, Mongo shell or Elasticsearch queries
execute_statementChanges data or structure. Only on Read & write connections

Settings ▸ MCP Server lists recent tool calls, so you can see what an AI app asked for.

If you move TabuloThe config points to where Tabulo is. After moving the app, click Add to Claude Desktop again.

Try it

Ask Claude something like:

  • "Using Tabulo, which customers in Kotor have more than five orders?"
  • "Describe the orders table in my local Postgres and suggest an index for status lookups."
