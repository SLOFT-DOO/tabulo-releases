Query editor

Each query tab speaks the connection's own language, with highlighting, autocomplete, several result tabs and a history you can search.

Run queries

  1. Open a query tab

    Press ⌘T, or right-click a table ▸ New Query From Here for a tab that starts with a query on that table.

  2. Write

    Autocomplete suggests tables, columns and keywords as you type. Press Esc or ⌃Space to show it.

  3. Run

    ⌘↵ runs the statement under the cursor, or the selection if you selected text. ⇧⌘↵ runs everything. Each statement that returns rows gets its own result tab.

  4. Reuse

    History lists past queries for this connection, newest first, with a search field.

Languages

PostgreSQL and SQLite

Plain SQL. Statements are split on semicolons, and quotes, comments and $$ dollar quoting are understood.

MySQL and MariaDB

Plain SQL. `backtick` identifiers, # comments and \' escapes inside strings are understood when splitting statements.

SHOW TABLES;
SELECT city, COUNT(*) AS customers FROM shop.customers GROUP BY city ORDER BY 2 DESC;
UPDATE shop.orders SET status = 'paid' WHERE id = 42;   # shows "1 affected"

Redis

One command per line.

HGETALL user:1
SCAN 0 MATCH session:* COUNT 100
SET feature:new-checkout on EX 3600

MongoDB

Shell syntax. ObjectId("…") and ISODate("…") work everywhere, including grid cells and filters.

db.users.find({ age: { $gt: 30 } }).sort({ name: 1 }).limit(20)
db.orders.aggregate([{ $group: { _id: "$status", n: { $sum: 1 } } }])
db.orders.updateMany({ status: "new" }, { $set: { status: "paid" } })
show collections

Also supported: insertOne/Many, deleteOne/Many, distinct, countDocuments, createIndex, getIndexes, drop, db.runCommand({…}) and show dbs.

Elasticsearch

Kibana Dev Tools requests, or SQL through the SQL API.

GET /products/_search
{ "query": { "match": { "name": "lamp" } }, "size": 20 }

GET _cat/indices?v

SELECT category, AVG(price) FROM products GROUP BY category

Search hits, SQL results and _cat tables open as grids. Other responses show as formatted JSON.
