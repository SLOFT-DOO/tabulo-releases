Troubleshooting

Answers to the problems people run into most.

"Tabulo can't be opened" on first launch

macOS shows this for apps not yet signed with an Apple Developer ID. Right-click Tabulo in Applications ▸ Open ▸ Open. On macOS 15, if there's no Open button, go to System Settings ▸ Privacy & Security and click Open Anyway. You only do this once.

Tabulo asks for a password every time

Edit the connection and turn on Save password in Keychain. If macOS asks whether Tabulo may use the Keychain item, click Always Allow.

Can't connect to a server

  • Click Test in the connection form to see the server's error.
  • Check host and port. Docker containers often use a different port on your Mac than inside the container.
  • For PostgreSQL in the cloud, try SSL mode: Require.
  • MySQL "Access denied for user": check the user and password, and that the user may connect from your Mac's address ('user'@'%' or your IP), not only from localhost.
  • For Elasticsearch, check that the URL starts with the right http:// or https://, and whether it needs an API key.
  • Elasticsearch says the certificate isn't trusted: a local cluster usually has a self-signed certificate. Set TLS mode to Custom CA certificate and choose its http_ca.crt, or to Allow invalid certificates (insecure).
  • A bootstrap command failed: the error names the command. Fix or remove it under Bootstrap commands in the connection form.

An edit or import failed

Open the Console (⇧⌘L) to see the statement and the database's error. On PostgreSQL, SQLite and MySQL (InnoDB) the whole change was rolled back, so nothing was half-written.

Claude doesn't see Tabulo

  • Restart Claude Desktop after adding the server.
  • If you moved Tabulo, click Add to Claude Desktop again in Settings ▸ MCP Server.
  • Connections set to Off are hidden from AI apps on purpose.

Updates don't appear

Choose Tabulo ▸ Check for Updates…. If you skipped a version, Tabulo stays quiet until a newer one comes out. Check that Settings ▸ Updates has automatic checks on.

Where Tabulo keeps your data

WhatWhere
Saved connections~/Library/Application Support/Tabulo/connections.json
Folders~/Library/Application Support/Tabulo/folders.json
Query history~/Library/Application Support/Tabulo/history.json
PasswordsmacOS Keychain, items named Tabulo

To move to a new Mac, use ⋯ ▸ Export Connections… and Import Connections… in the welcome window, then enter the passwords again.

Still stuck?

Report it on the releases page repository with your macOS version, Tabulo version (Settings ▸ Updates) and what the Console shows.
