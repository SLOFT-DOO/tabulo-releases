Export data

Export one or many tables to CSV, JSON, SQL, Excel or Markdown, as a file or to the clipboard.

Tutorial: export two tables to Excel

  1. Open Export

    Choose File ▸ Export… (⇧⌘E) or right-click a table ▸ Export….

  2. Pick tables

    Tick customers and orders. All selects everything, and the filter field narrows a long list.

  3. Pick the format

    Click Excel. Several tables go into one workbook with a sheet per table.

  4. Set the options

    See the table below. Then click Export… and choose where to save.

Options

FormatOptions
CSVField names in the first row, delimiter, always quote values, NULL as empty, line breaks as spaces
JSONAn array of objects per table
SQLCREATE TABLE, DROP TABLE, INSERT statements in batches; several tables in one file
ExcelOne .xlsx workbook, one sheet per table
MarkdownA table per database table, ready to paste into docs or an issue

Which rows

Export all rows (Tabulo pages through the server, so large tables work) or only the rows the current tab shows with its filter and sort. For CSV, JSON and Markdown with several tables, you can also write one file per table into a folder.

Quick export

The export button under a grid saves or copies the current page, or a query result, in any of the formats.

Connections

To share your saved connections, use ⋯ ▸ Export Connections… in the welcome window. Passwords are never included.
