Change structure

The Structure view edits columns, indexes and foreign keys in a grid. Tabulo writes the DDL, shows it to you, and runs it in one transaction.

Open it

Switch a table tab from Data to Structure, or right-click a table ▸ Open Structure. It has three lists: Columns, Indexes and Foreign Keys.

Tutorial: add a column and an index

  1. Add the column

    In Columns, click + (Add column). Name it shipped_at, choose the type TIMESTAMP, and leave Nullable ticked. The row turns green.

  2. Change another column

    Edit status: set the default to 'new' and untick Nullable. The row turns yellow.

  3. Add an index

    Switch to Indexes, click +, and pick status. Expressions and DESC columns are allowed.

  4. Review & commit

    Click Review & Commit… (⌘S). Tabulo shows the full DDL. Click Commit to run it in one transaction.

What you can change

WhereChanges
ColumnsAdd, drop or restore, duplicate, rename, type, nullable, default, comment, primary key (also composite)
IndexesCreate and drop, unique, expressions, DESC
Foreign keysAdd and drop (PostgreSQL, MySQL, SQLite)
TableRename it in the name field next to the lists

Pending changes use the same colours as in the grid: green new, yellow changed, red dropped. The undo arrow on a row reverts it. Definition shows the table's current CREATE statement.

MySQL

MySQL commits every DDL statement on its own, so Tabulo puts the whole change into one ALTER TABLE. MySQL 8 applies a single ALTER atomically: either every change lands, or none does. Changed columns are written with CHANGE COLUMN and their full definition, keeping AUTO_INCREMENT.

ALTER TABLE `orders`
  CHANGE COLUMN `qty` `quantity` int NOT NULL DEFAULT 5,
  ADD COLUMN `shipped_at` datetime NULL COMMENT 'when it left',
  ADD INDEX `idx_quantity` (`quantity` DESC);

SQLite

SQLite's ALTER TABLE can't change a column's type, NOT NULL, default or keys. For those, Tabulo does the rebuild SQLite documents: it creates the new table, copies the rows, and recreates indexes, UNIQUE constraints, foreign keys and AUTOINCREMENT. You see every statement in the review first.

MongoDB and Redis

MongoDB shows the fields Tabulo infers from documents, and lets you create and drop indexes. Redis shows server information from INFO.
