Safe mode & environments

Tag each connection with its environment, and make Tabulo ask before anything changes data where it matters.

Environments

EnvironmentColourBehaviour
LocalGreyNormal
DevelopmentGreenNormal
TestingBlueNormal
StagingOrangeNormal
ProductionRedAlways in Safe mode

Set it in the connection form under Environment. The colour shows in the connection list and in the workspace window.

Safe mode

Turn on Safe mode in the connection form ("Review and confirm every statement that changes data"). It's always on for production. With it on:

  • Committing edits always opens the review first, even with ⌘S.
  • Running a statement in the query editor that modifies data asks for confirmation.
  • The workspace toolbar shows Safe mode.

Other safeguards

  • Truncate… and Drop… in the sidebar always ask first.
  • Edits and structure changes run in one transaction where the engine supports it.
  • The Console (⇧⌘L) shows every statement Tabulo ran.
  • AI apps get Read only access unless you choose otherwise (see AI access).
