Keyboard shortcuts

Everything you can do from the keyboard. Menus show the same shortcuts.

Anywhere

KeysAction
⌘POpen anything (jump to a table)
⌘TNew query tab
⇧⌘TNew tab (the next table you pick fills it)
⇧⌘WClose tab
⇧⌘] / ⇧⌘[Next / previous tab
⌘RRefresh
⇧⌘IImport from CSV
⇧⌘EExport tables
⌥⌘0Show or hide the right panel
⌥⌘IRow details
⇧⌘LConsole log

Data grid

KeysAction
⌘SCommit changes
⇧⌘SReview changes
⌘IAdd row
⌘DDuplicate row
⌫Delete selected rows
⌘CCopy selected rows as tab-separated text
⌥⌘FShow or hide filters
⌘] / ⌘[Next / previous page
↵ / ⇥Finish editing a cell / move to the next cell

Query editor

KeysAction
⌘↵Run the statement under the cursor, or the selection
⇧⌘↵Run all statements
Esc or ⌃SpaceShow autocomplete
