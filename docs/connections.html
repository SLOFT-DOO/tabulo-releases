Connections & folders

A connection stores how to reach one database. Save as many as you like, group them in folders, and tag each with its environment.

Create a connection

  1. Start a new connection

    In the welcome window click New Connection and pick the engine: PostgreSQL, MySQL, SQLite, Redis, MongoDB or Elasticsearch.

  2. Fill in the server

    Give it a Name, then the host, user, password and database. Port is optional: leave it empty to use the default shown in grey (5432, 3306, 6379, 27017). For MySQL, leave Database empty to see every database on the server, or fill it in to work in one. Elasticsearch takes a URL instead, such as https://my-cluster.es.io. MongoDB also takes a full connection string such as mongodb+srv://…, which overrides host, port and user. For SQLite, choose the database file.

  3. Pick the SSL mode

    New PostgreSQL and MySQL connections use Prefer: encrypted when the server supports it, plain otherwise. Choose Require to always encrypt, or Verify CA / Verify Full to also check the server's certificate.

  4. Choose an environment

    Set Environment to local, development, testing, staging or production. The colour shows in the connection list and the window, so you always know where you are. Production connections always ask before changing data (see Safe mode).

  5. Save the password

    Leave Save password in Keychain on to store it in the macOS Keychain. Turn it off and Tabulo asks each time you connect.

  6. Test, then save

    Click Test to check the details, then Save. Double-click the connection to open it, or select it and click Connect.

Host, port and sockets

  • Host also takes db.internal:5433 or [::1]:5433. The port written there wins over the Port field.
  • Paste a whole connection URL into Host and Tabulo fills in host, port, user, password, database and SSL mode.
  • For PostgreSQL, MySQL and Redis, Host/Socket takes a Unix socket path instead: /tmp or /var/run/postgresql for PostgreSQL (Tabulo adds .s.PGSQL.5432, using the port), /tmp/mysql.sock for MySQL, /tmp/redis.sock for Redis. Sockets work over SSH too.

Bootstrap commands

PostgreSQL and MySQL connections can run SQL every time they connect, for example to set the schema search path or the time zone.

  1. Open the editor

    In the connection form, next to Bootstrap commands, click Add….

  2. Type the statements

    For example SET search_path TO app, public; or SET time_zone = '+00:00';. They run in order.

  3. Click Done, then Save

    If a command fails, the connection stops with that command's error, so a typo doesn't go unnoticed.

Elasticsearch URL and TLS mode

  • URL is the whole address: http://localhost:9200, https://my-cluster.es.io or https://gateway.example.com/es. The port is optional: 443 for https, 80 for http.
  • A user:password@ in the URL moves to User and Password or API key when you test or save, so the password goes to the Keychain.
  • For https URLs, TLS mode decides which certificates are accepted: System CA (default) for certificates macOS trusts (Elastic Cloud), Custom CA certificate for Elasticsearch's own http_ca.crt, and Allow invalid certificates (insecure) for self-signed local clusters.

Import from a URL

Click Import URL… and paste a connection URL. Tabulo fills in the form for you. URLs copied from TablePlus work too, including the connection name, the environment and SSH tunnels.

postgres://app:secret@db.internal:5432/shop?sslmode=require
mysql://root@127.0.0.1:3306/shop
mariadb://app@db.internal/shop
redis://127.0.0.1:6379/2
mongodb://admin@localhost:27017/orders
mongodb+srv://cluster0.example.net/orders
https://elastic@my-cluster.es.io
postgresql+ssh://deploy@bastion.example.com/app@127.0.0.1/shop
/Users/you/data/demo.sqlite

To share a connection, right-click it ▸ Copy as URL. Copy as URL with Password includes the saved password.

Organise with folders

  • New Folder at the bottom of the welcome window creates one.
  • Drag connections into a folder, or right-click a connection ▸ Move to Folder.
  • Drag a connection to Connections to take it out of a folder.
  • Right-click a folder to rename it, delete it, or add New Connection Here. Deleting a folder keeps its connections.
  • Folders remember whether they're open or collapsed.

More actions

  • Search connections at the top filters the list as you type.
  • Right-click a connection to Edit…, Duplicate or Delete…. Deleting also removes its saved password from the Keychain.
  • The ⋯ menu has Export Connections… and Import Connections…. The file is JSON and never includes passwords, so it's safe to share with your team.
