Tabulo documentation

Tabulo is a native Mac app for working with PostgreSQL, MySQL, SQLite, Redis, MongoDB and Elasticsearch. These pages explain every part of it, with step-by-step tutorials.

New to Tabulo? Install it, then follow Your first connection. It takes about five minutes and uses a small SQLite file, so you don't need a server.
