Install & update

Tabulo comes as a disk image. You drag the app into Applications once, and after that it keeps itself up to date.

RequirementsmacOS 14 Sonoma or later, on a Mac with Apple silicon (M1 or newer).

Install Tabulo

  1. Download the disk image

    Get Tabulo.dmg, the newest version. Older versions are on the releases page.

  2. Open it

    Double-click Tabulo.dmg in Downloads. A window opens with the Tabulo icon on the left and your Applications folder on the right.

  3. Drag Tabulo onto Applications

    Drop the icon on the Applications folder. macOS copies the app. If an older Tabulo is there, choose Replace; your saved connections are kept.

  4. Eject the disk image

    In Finder's sidebar, click the eject button next to Tabulo. You can delete the .dmg file afterwards.

  5. Open Tabulo the first time

    Open Applications, right-click Tabulo ▸ Open, then click Open in the dialog. After that, open it normally from Launchpad, Spotlight or the Dock.

Why right-click ▸ Open?Tabulo isn't signed with an Apple Developer ID yet, so on first launch macOS says it "can't check the app for malicious software". Right-click ▸ Open tells macOS you trust it. On macOS 15, if there's no Open button, go to System Settings ▸ Privacy & Security and click Open Anyway next to the Tabulo message. You only do this once.

Updates

Tabulo checks for a new version when it starts and once a day. When one is out, it shows what changed and three buttons:

  • Install Update downloads the new version, checks its signature, and relaunches Tabulo.
  • Remind Me Later asks again at the next check.
  • Skip This Version stays quiet until a newer one comes out.

To check right away, choose Tabulo ▸ Check for Updates…. More in In-app updates.

Uninstall

  1. Quit Tabulo and drag it from Applications to the Bin.
  2. To remove your saved connections and query history too, delete ~/Library/Application Support/Tabulo.
  3. Saved passwords are in the Keychain. Open Keychain Access, search for Tabulo, and delete the entries.
